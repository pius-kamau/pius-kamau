## About Me

I'm **Pius Kamau**, a Backend Software Engineer and the founder of **Pitech Technologies**, based in Nairobi, Kenya.

I build backend systems with a focus on **API engineering, database architecture, authentication, real-time systems, background processing, and production reliability**.

My approach is centered around building software that is:

* **Scalable** — designed to handle growing workloads
* **Secure** — strong authentication, authorization and defensive engineering
* **Maintainable** — clean architecture and clear separation of concerns
* **Observable** — structured logging, monitoring and error handling
* **Production-ready** — containerized, documented and deployment-conscious

### What I Work On

* Backend architecture and API development
* RESTful API design
* Database modeling and optimization
* Authentication and authorization
* Redis caching and distributed locking
* Real-time applications
* Background job processing
* Payment integrations
* Dockerized deployments
* System design and backend infrastructure
